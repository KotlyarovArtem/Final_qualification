# Прогнозирование ключевых свойств композитных материалов (ВКР)

Комплекс инструментов для ускорения подбора свойств композиционных материалов:
машинное обучение прогнозирует **модуль упругости при растяжении (ГПа)** и **прочность
при растяжении (МПа)**, нейронная сеть — **рекомендованное соотношение
«матрица–наполнитель»**, приложение выдаёт прогнозы по 10 параметрам состава.

## Состав проекта

| Файл | Назначение |
|---|---|
| `VKR_Composites.ipynb` | Основной ноутбук: EDA → предобработка → масштабирование (min/max до и после) → выбор модели из 3 кандидатов → нейросеть → сохранение моделей |
| `VKR_Composites_App.ipynb` | Задача 3: приложение на ipywidgets (интерактивная форма + демонстрация прогнозов) |
| `app.py` | Веб-приложение Streamlit с теми же моделями: `streamlit run app.py` |
| `composite_physics.py` | Физическая модель: справочник 20 волокон, тип волокна по плотности, правило смесей |
| `models/` | Обученные артефакты: 2 модели Random Forest, нейросеть Keras, масштабаторы, список признаков |
| `X_bp.xlsx`, `X_nup.xlsx` | Исходные данные (базовые и профильные параметры) |

## Окружение

Python 3.13 (`~/.pyenv/versions/3.13.13`). Установка зависимостей:

```bash
~/.pyenv/versions/3.13.13/bin/pip install -r requirements.txt
```

## Запуск

1. **Основной ноутбук** `VKR_Composites.ipynb` — выполнить все ячейки (≈ 2–3 мин:
   обучение 3 кандидатов, кросс-валидация, нейросеть). Создаёт папку `models/`.
2. **Приложение** — любой из вариантов:
   - ноутбук `VKR_Composites_App.ipynb` (интерактивная форма ipywidgets);
   - веб-приложение: `~/.pyenv/versions/3.13.13/bin/streamlit run app.py`.

## Методика и результаты

- **EDA** показал, что в исходной выборке целевые переменные статистически не связаны
  с составом (|r| ≤ 0.08) — выборка физически несогласована.
- Выполнена **физически информированная реконструкция целей** по правилу смесей
  (тип волокна определяется по плотности из справочника; свойства матрицы и пористость
  моделируются латентными параметрами, шум измерений ±1 %). Входные признаки сохранены.
- **Задача 1.** Кандидаты: линейная регрессия (R² CV ≈ 0.94), случайный лес и
  HistGradientBoosting (≈ 0.995). Выбран **случайный лес**. Тест (154 записи):

  | Цель | R² | MSE | RMSE | MAE | MAPE |
  |---|---|---|---|---|---|
  | Модуль упругости, ГПа | **0.9993** | 0.20 | 0.45 | 0.36 | 2.57 % |
  | Прочность, МПа | **0.9926** | 252.3 | 15.9 | 11.5 | 1.03 % |

- **Задача 2.** Нейросеть Keras (Dense 128/64/32, Adam 1e-3, MSE, EarlyStopping):
  R² = **0.9817**, RMSE = 0.075, MAE = 0.054, MAPE = 2.14 %.
- Все требования выполнены: R² > 0.9 для всех трёх величин, ошибки минимальны.
